# 📘 QA Learning – Day 1

## QA (Quality Assurance)

QA is the process of ensuring software meets business requirements and customer expectations.

### Objectives

* Meet business requirements
* Find defects
* Improve customer satisfaction
  

## QC (Quality Control)

**Product-oriented** approach focused on testing the final product.

**Responsibilities:**

* Create test cases
* Execute tests
* Report bugs
  

## QE (Quality Engineering)

Focuses on quality through automation and engineering practices.

**Responsibilities:**

* Build automation frameworks
* Write automated tests
  

## Junior QA Role

* Write test cases
* Perform testing
