# 🚀 QA Learning Roadmap (4 Weeks)

A structured roadmap covering **Manual Testing, API Testing, Database Testing, Python, and Selenium Automation** with hands-on practice and interview preparation.

---

## 📅 Week 1: QA Foundations & Manual Testing

### Topics

* Software Testing Fundamentals
* QA vs QC vs QE
* SDLC (Waterfall, Agile, Scrum)
* STLC
* Types of Testing
* Manual vs Automation Testing
* Functional vs Non-Functional Testing
* Smoke, Sanity & Regression Testing
* System, Integration & UAT
* Black Box vs White Box Testing
* Bug Life Cycle
* Severity vs Priority
* Writing Bug Reports

### Hands-On

* Identify and report bugs
* Daily interview Q&A practice

---

## 📅 Week 2: Advanced Manual Testing & API Testing

### Topics

* Test Design Techniques

  * Equivalence Partitioning
  * Boundary Value Analysis
  * Decision Table Testing
  * State Transition Testing
* Test Documentation
* REST API Basics
* HTTP Methods (GET, POST, PUT, DELETE)
* Status Codes
* Headers, Body & Query Parameters
* Postman

### Hands-On

* API testing with Postman
* Validate JSON responses
* Write test cases for a web application
* API interview practice

---

## 📅 Week 3: Database Testing & Python Basics

### Database Testing

* SQL Basics

  * UPDATE
  * DELETE

### Python for QA

* Python Setup
* Variables & Data Types
* Conditions
* Loops
* Functions
* Exception Handling

### Hands-On

* Write Python scripts
* QA coding exercises
* Python interview questions

### Selenium

### Framework Basics

* Page Object Model (POM)

### Interview Preparation

* Selenium Interview Questions
* Practical Automation Exercises
